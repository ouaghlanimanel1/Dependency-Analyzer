# Dependency Analyzer

## Overview

Dependency Analyzer is a full-stack application designed to help development teams monitor and analyze software dependencies across multiple products. It provides visibility into dependency usage, duplication, and version distribution to support better dependency management.

## Key Features

- **Dependency Monitoring:** Collect and organize dependency information from artifact repositories.
- **Unused Dependency Detection:** Help identify dependencies that may no longer be required.
- **Duplicate Dependency Analysis:** Highlight libraries shared across multiple products.
- **Version Proliferation Monitoring:** Track the distribution of dependency versions.
- **Interactive Dashboard:** Present dependency insights through a centralized interface.
- **Repository Integration:** Support integration with artifact repositories such as Nexus and Artifactory.

## Technology Stack

- **Frontend:** Angular
- **Backend:** Java, Spring Boot
- **Database:** PostgreSQL
- **Repository Management:** Nexus Repository, JFrog Artifactory

## Project Goals

- Improve visibility into software dependencies.
- Facilitate dependency maintenance across products.
- Help development teams identify potential dependency-management issues.
- Support more informed decisions about dependency usage and version consistency.
